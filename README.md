
# Student Task Manager

A beginner-friendly Java project built to practise Java, Git, and GitHub.

## Features

- Add tasks
- View all tasks
- Delete tasks
- Mark tasks as completed
- Save tasks between program runs

## Technologies Used

- Java
- Git
- GitHub
- VS Code

## How to Run

1. Install the Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac Main.java

5. Run the program:

   java Main
